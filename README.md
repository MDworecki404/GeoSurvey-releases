# GeoSurvey — instalatory

Nowoczesny program geodezyjny dla polskich geodetów (Windows 10/11, 64-bit).
Tu są wyłącznie instalatory i paczki aktualizacji. Kod źródłowy jest prywatny.

## Instalacja

1. Otwórz [najnowsze wydanie](https://github.com/MDworecki404/GeoSurvey-releases/releases/latest).
2. Pobierz **`GeoSurvey-win-Setup.exe`** i uruchom.
3. Windows może pokazać okno „System Windows ochronił ten komputer” — program nie jest jeszcze
   podpisany cyfrowo. Kliknij **Więcej informacji**, potem **Uruchom mimo to**.
4. Program zainstaluje się dla bieżącego użytkownika (bez uprawnień administratora)
   i doda skrót do menu Start oraz na pulpit.

Wersja przenośna (bez instalacji): `GeoSurvey-win-Portable.zip` — rozpakuj i uruchom `GeoSurvey.exe`.

## Aktualizacje

Program sam sprawdza przy starcie, czy jest nowa wersja, i pobiera ją w tle. Na pasku stanu pojawi się
„Wersja X gotowa — uruchom ponownie”; aktualizacja zainstaluje się po kliknięciu albo przy zamknięciu
programu. Sprawdzanie można wyłączyć w oknie **Pomoc → O programie**.

## Odinstalowanie

Ustawienia systemu → Aplikacje → GeoSurvey → Odinstaluj. Projekty (`.gsp`) i ustawienia programu
w `%AppData%\GeoSurvey` pozostają na dysku.
